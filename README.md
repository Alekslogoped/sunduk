# Кролик-пират и код сокровищ

Детская игра на сложение и вычитание: пять ответов открывают сундук, три сундука дают самоцвет, золотую морковку и корону. Русский интерфейс, подсказки счётными кружками, клавиатура и сенсорная панель, отключаемые синтезированные звуки. Без таймера, регистрации, внешних CDN и API-ключей.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте адрес этого сервера в своём браузере. Сборка и установка зависимостей игре не нужны. Для облачной среды сервер запускается в управляемом терминале; инструкция также сохранена в `start_skill`. Внешняя публикация выполняется отдельно.

Файлы: `index.html`, `styles.css`, `game.js`, `assets/`. Все картинки поставляются локально из пользовательского комплекта `pirate-treasure-codex-kit.zip`. Исходные атласы не используются при показе игры.

## Управление

Выберите карточку или окошко и введите цифру. После ввода выбирается следующий пустой ответ. Можно исправлять заполненные позиции. Кнопка открытия доступна только после пяти цифр. Ошибка не стирает код и не ограничивает попытки.

Цифры 0–9 — ввод, Backspace/Delete — удаление, стрелки — выбор, Enter — проверка. Внутри iframe сначала нажмите на игру. В окне правил клавиши игры не перехватываются. На маленьких экранах панель ввода и увеличенный выбранный пример вынесены под сцену. Для полного размера иллюстраций удобнее горизонтальная ориентация.

## GitHub Pages

1. Разместите файлы проекта в репозитории, сохранив структуру `assets`.
2. В GitHub откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку с файлами игры и папку **/(root)**.
4. Дождитесь успешного развёртывания и используйте адрес, который покажет GitHub Pages.

Относительные пути поддерживают публикацию в подпапке. Настройки Pages и опубликованный адрес в рамках этой работы не проверялись; изменения подготовлены в локальном checkout `Alekslogoped/sunduk`.

## Genially

После публикации замените `PUBLISHED_GAME_URL` настоящим адресом:

```html
<iframe
  src="PUBLISHED_GAME_URL"
  width="100%"
  height="100%"
  title="Кролик-пират и код сокровищ"
  allow="fullscreen"
  allowfullscreen>
</iframe>
```

Контейнер в Genially должен иметь соотношение 16:9 и ненулевую высоту. Игра не обращается к родительскому DOM. Встраивание в локальный iframe проверено; добавление в сам Genially выполняется отдельно.

## Проверки

Игра не требует Node.js. Только для автоматических браузерных проверок нужен Playwright и Chromium. Установите тестовый инструмент вне репозитория:

```sh
npm install --prefix /tmp/sunduk-browser --cache /tmp/npm-cache playwright
NODE_PATH=/tmp/sunduk-browser/node_modules node tests/browser.cjs
```

Тест ожидает уже запущенный HTTP-сервер. По умолчанию используется Chromium `/usr/bin/chromium`. Переопределения: `CHROMIUM_PATH` и `GAME_URL`. Скриншоты сохраняются в `/tmp/sunduk-*.png`. Результаты — в [docs/TEST_REPORT.md](docs/TEST_REPORT.md).

`window.PirateGame` предоставляет генератор, проверку кода и копию состояния только для диагностики; изменение полученной копии не меняет игру. Анимационная последовательность использует один цикл requestAnimationFrame: перезапуск сбрасывает её время, а скрытие вкладки приостанавливает ход сценки и звук. Точки крепления заданы в CSS, основные параметры — в CONFIG в `game.js`.
