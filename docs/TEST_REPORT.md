# Отчёт проверки

Проверено в настоящем headless Chromium через Playwright в текущей облачной среде. Сервер — Python 3.12, игра — обычные статические файлы.

## Автоматические проверки

Команда: `NODE_PATH=/tmp/sunduk-browser/node_modules node tests/browser.cjs`.

- 3 000 сгенерированных раундов: диапазоны операндов и ответов, целочисленность, оба действия, уникальность выражений внутри игры.
- Ноль, код с начальным нулём, отличие пустой позиции от нуля и контрольный код 53819.
- Неполный код нельзя проверить; цифры вводятся и удаляются.
- Ошибочный код сохраняется, ошибки отмечаются, исправленная позиция теряет отметку.
- Подсказка открывается и закрывается; диалог правил не пропускает цифры в игру.
- Двойная активация не создаёт повторную сценку. Перезапуск во время сценки отменяет выдачу награды и очищает код.
- Все три награды, переходы только по кнопке и чистый повтор игры.
- Широкий экран 1600×900, планшет 1024×768, вертикальный экран 390×844. Кнопки цифровой панели на небольшом экране не ниже 44 CSS px, горизонтальной прокрутки нет.
- В iframe: экранные кнопки и клавиатура после выбора карточки.
- Короткая последовательность при prefers-reduced-motion.
- Смена головы при моргании и отдельное вращение уха действительно происходят.
- При отсутствии PNG появляется понятное сообщение об ошибке.
- Нет ошибок JavaScript и HTTP-ошибок загрузки ресурсов.

## Визуальная проверка

Просмотрены скриншоты сцены, собранного персонажа, подхода к сундуку, извлечения и показа награды, помещения в мешок и финала. Подстроены перекрытие плеч, направление лапки, её точка захвата и крепление крышки. Предмет использует координаты точки захвата в той же масштабируемой сцене, передняя стенка сундука и маска мешка скрывают соответствующие участки.

## Остаётся проверить на целевых устройствах

- Звучание синтезированных сигналов на слух и особенности мобильного Safari.
- Пауза/возобновление при реальном сворачивании браузера на планшете.
- Удобство для конкретного ребёнка и педагога, особенно на небольшом вертикальном телефоне.
- Публикация GitHub Pages и реальное встраивание в аккаунт Genially: внешнее развёртывание не выполнялось.

Локальные браузерные проверки не означают, что сайт уже опубликован или настройки Genially выполнены.
